# Subsystem Verification: 25 Architectural Claims

This document evaluates 25 distinct, falsifiable claims regarding the Clypra Program Preview subsystem against version-controlled source code, automated test results, telemetry records, and empirical observations.

---

## Evaluation Taxonomy
- **VERIFIED**: Substantiated by deterministic code inspection and passing automated regression tests.
- **QUALIFIED**: True under specific configurations, but subject to documented constraints or hardware fallbacks.
- **FALSIFIED**: Directly contradicted by codebase implementation or test results.
- **UNMEASURED**: Plausible architectural design lacking instrumentation or benchmark data.
